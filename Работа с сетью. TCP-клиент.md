### Transmission Control Protocol

Transmission Control Protocol, протокол управления передачей. TCP также как и UDP является протоколом транспортного уровня и решает две основные задачи: сегментация данных, приходящих с уровня приложений с уровня приложений и адресация приложений (передающего и принимающего) при помощи портов

TCP обеспечивает: 
- Надежную доставку сегментов
- Упорядочивание сегментов при получении
- Работу с сессиями
- Контроль за скоростью передач


### Структура пакета TCP

- Source port (16 бит): порт источника
- Dectination port (16 бит): порт назначения
- Sequence number, SYN (32 бита): порядковый номер сегмента данных
- Acknowledgement number, ACK (32 бита): номер подтверждения сегмента данных
- Data offset (4 бита): длина заголовка, известная также как смещение данных. Содержит размер заголовка TCP, измеряемый в 32-битных сегментах. Минимальный размер заголовка TCP составляет пять 32-битных сегментов (всего 20 байт), а максимальный - пятнадцать 32 битных сегмента (или 60 байт)
- NS (1 бит): одноразовая сумма (Nonce Sum)
- CWR (1 бит): окно перегрузки уменьшено (Congestion Window Reduced)
- ECE (1 бит): ECN-Эхо (ECN-Echo)
- URG (1 бит): Устанавливается, если необходимо передать ссылку на поле указателя срочности (Urgent pointer)
- ACK (1 бит): устанавливается, когда пакет содержит значение номера подтверждения в поле подтверждения
- PSH (1 бит): делает этот пакет пакетом PUSH (проталкивания)
- RST (1 бит): сброс данного соединения
- SYN (1 бит): начинает соединение и синхронизирует порядковые номера
- FIN (1 бит): одна из конечных точек отправляет пакет с установленным флагом FIN для другой конечной точки, чтобы сообщить, что все пакеты были отправлены, соединение пора завершить
- Window size (16 бит): размер окна приема
- Checksum (16 бит): контрольная сумма
- Urgent pointer (16 бит): указатель срочности


### Надежная доставка пакета

- Под надежной доставкой подразумевается автоматическая повторная пересылка недошедших сегментов
- После отправления нескольких сегментов узел ожидает подтверждения их получения
- Если подтверждение не приходит узел повторяет передачу еще несколько раз
