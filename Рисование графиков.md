### Что такое графики

График - это визуальное представление числовых данных

Графики в основном необходимы для того, чтобы наглядно представить результаты эксперимента 


### Qt Charts

Модуль Qt Charts предоставляет набор простых в использовании графиков. Qt Charts использует Qt Graphics View Framework для интеграции графиков с пользовательскими интерфейсами

Подключение:
```
find_package(Qt6 REQUIRED COMPONENTS Charts)
target_link_libraries(mytarget PRIVATE Qt6::Charts)

QT += charts
```


### Построение линейных графиков

```
QSplineSeries *series = new QSplineSeries();
series->setName("spline");

series->append(0, 6);
series->append(2, 4);
series->append(3, 8);
series->append(7, 4);
series->append(10, 5);
*series << QPoint(11, 1) << QPointF(13, 3) << QPointF(17, 6) << QPointF(18, 3) << QPointF(20, 2);
```


### QCustomPlot

QCustomPlot - это виджет Qt C++ для построения графиков и визуализации данных. QCustomPlot не имеет дополнительных зависимостей

Подключение:
```
find_package(Qt6 COMPONENTS PrintSupport REQUIRED)
target_link_libraries(target PRIVATE Qt6::PrintSupport)

QT += PrintSupport
```

```
find_package(Qt6 REQUIRED COMPONENTS Widgets PrintSupport)
add_compile_definitions(QCUSTOMPLOT_USE_LIBRARY)
target_link_directories(${PROJECT_NAME} PUBLIC ${CMAKE_CURRENT_SOURCE_DIR})
target_link_libraries(CreateCustomPlot PRIVATE Qt6::Widgets Qt6::PrintSupport qcustomplot2)

DEFINES += QCUSTOMPLOT_USE_LIBRARY

CONFIG(debug, release|debug)
{
	win32:QCPLIB = qcustomplotd2
	else: QCPLIB = qcustomplotd
} else
{
	win32:QCPLIB = qcustomplot2
	else: QCPLIB = qcustomplot
}

LIBS += -L$$PWD -l
```
