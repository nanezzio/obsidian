### Что такое графики

График - это визуальное представление числовых данных

Графики в основном необходимы для того, чтобы наглядно представить результаты эксперимента 


### Qt Charts

Модуль Qt Charts предоставляет набор простых в использовании графиков. Qt Charts использует Qt Graphics View Framework для интеграции графиков с пользовательскими интерфейсами

Подключение:
```
find_package(Qt6 REQUIRED COMPONENTS Charts)
target_link_libraries(mytarget PRIVATE Qt6::Charts)

QT += charts
```
