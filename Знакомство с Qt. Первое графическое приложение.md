### Графическое приложение

Графическое приложение - приложение, у которого присутствует графический интерфейс пользователя (ПИ или GUI)

Интерфейс пользователя:
интерфейс пользователя -> ОС -> ПО


### Развитие GUI

1. Взаимодействие пользователя с ПО с помощью перфокарт
2. Появление клавиатуры (1950-е годы)
3. Появление командных, а затем текстовых интерфейсов (1960-1970 гг.)
4. Появление полноценных GUI


### Новые требования к разработке ПО

- Естественность - интерфейс должен быть привычен пользователю
- Эстетичность - пользователь не должен впадать в шок от вида приложения
- Простота - не должно быть множества непонятных кнопок, настроек, сложных форм ввода, с которыми пользователю предстоит работать
- Дружественность - пользователь должен освоить программу максимально быстро


### Как создавать графические приложения

- Стандартными средствами ОС
- С помощью фреймворков

### Qt Creator и лицензии

Qt - это библиотека классов C++ и набор инструментального ПО для создания кросс-платформенных приложений с графическим интерфейсом (GUI)


### Лицензии Qt

- Коммерческая лицензия позволяет полностью закрывать исходные коды программ, модифицировать исходные тексты модулей Qt и распространять продукт любым удобным способом
- GPL. Программа должна быть открыта и свободно распространяться. Исходные тексты программы и все изменения в исходных текстов Qt должны быть в свободном доступе
- LGPL. Исходные тексты программы могут быть открытыми или закрытыми. Если программа закрытая и планируется ее коммерческое использование, Qt должен связываться с программой в виде динамических библиотек. Изменения в исходных кодах Qt запрещены


### Обязательные компоненты для выполнения заданий курса:
