### Графическое приложение

Графическое приложение - приложение, у которого присутствует графический интерфейс пользователя (ПИ или GUI)

Интерфейс пользователя:
интерфейс пользователя -> ОС -> ПО


### Развитие GUI

1. Взаимодействие пользователя с ПО с помощью перфокарт
2. Появление клавиатуры (1950-е годы)
3. Появление командных, а затем текстовых интерфейсов (1960-1970 гг.)
4. Появление полноценных GUI


### Новые требования к разработке ПО

- Естественность - интерфейс должен быть привычен пользователю
- Эстетичность - пользователь не должен впадать в шок от вида приложения
- Простота - не должно быть множества непонятных кнопок, настроек, сложных форм ввода, с которыми пользователю предстоит работать
- Дружественность - пользователь должен освоить программу максимально быстро
