### Модуль Qt SQL

3 уровня работы с БД:
1. Уровень драйверов. Низкоуровневые соединения с БД
2. Высокоуровневый API для взаимодействия с БД
3. Уровень отображения данных

Подключение:
```
find_package(Qt6 REQUIRED COMPONENTS Sql)
target_link_libraries(mytarget PRIVATE Qt6::Sql)

QT += sql
```


### Классы для работы с БД

- QSql - содержит различные перечисления, используемые во всем модуле Qt SQL (-)
- QSqlDatabase - интерфейсы для подключений к БД (API БД)
- QSqlDriver - абстрактный класс для работы с драйверами БД (Драйверов)
- QSqlDriverCreator - шаблонный класс, являющийся фабрикой для подклассов QSqlDriver (Драйверов)
- QSqlDriverCreatorBase - фабрика QSqlDriver (Драйверов)
- QSqlError - позволяет посмотреть ошибки полученный от БД (API БД)
- QSqlField - позволяет управлять свойствами столбцов таблиц БД (API БД)
- QSqlIndex - класс для работы с индексами БД (API БД)
- QSqlQuery - класс выполнения запросов к БД (API БД)
- QSqlQueryModel - класс для выполнения запросов и просмотров результатов
