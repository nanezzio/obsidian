### Модель OSI
- Media layers (уровни среды):
	1. Физический
	2. Канальный
	3. Сетевой
- Host layers (уровни хоста):
	4. Транспортный 
	5. Сеансовый
	6. Представления
	7. Прикладной


1. Физический уровень - отвечает за обмен физическими сигналами между физическими устройствами, "железом"
2. Канальный - отвечает за адресацию при передаче информации. Появляется понятие Frame(кадр). Адресация осуществляется MAC-адресам
3. Сетевой - отвечает за логическую маршрутизацию пакетов данных. На этом уровне работают все роутеры (маршрутизаторы) которые стоят у нас дома
4. Транспортный - по сути является посредником между Host Layers и Media Layers, относящийся скорее к первым, чем к последним. Его главной задачей является транспортировка пакетов
5. Сеансовый - отвечает за поддержание сеанса связи между приложениями. Сеансовый уровень синхронизует информацию, согласуя и поддерживая соединения между устройствами
6. Представления - отвечает за преобразование протоколов и кодирование\декодирование данных
7. Прикладной - предоставляет интерфейс к среде передачи для приложения, которое не относится к модели OSI. Задача седьмого уровня - использовать свои протоколы, чтобы пользователь увидел данные в понятном ему виде


### Address Resolution Protocol (APR)

Протокол определения адреса. Протокол позволяет определить какой MAC адрес в сети соответствует какому IP-адресу


### Межсетевой протокол (Internet Protocol)

IP протокол определяет адресацию сетевого уровня, а также задает способ, время и место перенаправления пакетов


### Internet Control Message Protocol (ICMP)
