### Модель OSI
- Media layers (уровни среды):
	1. Физический
	2. Канальный
	3. Сетевой
- Host layers (уровни хоста):
	4. Транспортный 
	5. Сеансовый
	6. Представления
	7. Прикладной


1. Физический уровень - отвечает за обмен физическими сигналами между физическими устройствами, "железом"
2. Канальный - отвечает за адресацию при передаче информации. Появляется понятие Frame(кадр). Адресация осуществляется MAC-адресам
3. Сетевой - отвечает за логическую маршрутизацию пакетов данных. На этом уровне работают все роутеры (маршрутизаторы) которые стоят у нас дома
4. Транспортный - по сути является посредником между Host Layers и Media Layers, относящийся скорее к первым, чем к последним. Его главной задачей является транспортировка пакетов
